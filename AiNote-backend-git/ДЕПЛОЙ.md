# Деплой backend на Railway (бесплатно, без вашего Mac)

## 1. Залить на GitHub

- Создайте новый репозиторий на github.com (кнопка New, имя любое, например `AiNote-backend`).
- На странице репозитория: "uploading an existing file" → перетащите ВСЁ содержимое
  этой папки (файлы и папки routes/, src/, middleware/, db/).
- `.gitignore` уже настроен — node_modules, .env, базы не попадут даже если случайно
  перетащите. Но лучше их и не тащить.
- Commit.

## 2. Развернуть на Railway

- Зайдите на railway.app, войдите через GitHub.
- New Project → Deploy from GitHub repo → выберите ваш репозиторий.
- Railway прочитает nixpacks.toml, поставит Node + ffmpeg + yt-dlp и запустит сервер.

## 3. Вписать секреты

В проекте на Railway: вкладка **Variables** → добавьте:

| Переменная | Значение |
|------------|----------|
| ANTHROPIC_API_KEY | ваш ключ Claude |
| JWT_SECRET | длинная случайная строка |
| CLAUDE_MODEL | claude-sonnet-5 (или claude-haiku-4-5-20251001) |

PORT задавать НЕ нужно — Railway подставит сам.

## 4. Получить публичный адрес

Settings проекта → Networking → Generate Domain.
Получите адрес вида `https://ainote-xxxx.up.railway.app`.

Проверьте в браузере: `https://ainote-xxxx.up.railway.app/health` → должно вернуть `{"status":"OK"}`.

## 5. Прописать адрес в приложении

В мобильном `App.js`, верхняя строка:

```js
const API_URL = 'https://ainote-xxxx.up.railway.app/api';
```

(именно https и с /api на конце)

## Важно знать

- **База SQLite на бесплатном тарифе может обнуляться при передеплое.** Для 10 человек
  и MVP это терпимо; если нужна стойкость — подключите Railway Volume (платно, ~1$/мес)
  и укажите DATABASE_PATH внутрь него.
- **Instagram/TikTok с облачного сервера скачиваются хуже**, чем с домашнего IP —
  платформы чаще блокируют серверные адреса. YouTube работает стабильно.
