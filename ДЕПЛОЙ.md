# Деплой backend на Railway (Gemini)

## Переменные в Railway → Variables

| Переменная | Значение |
|------------|----------|
| GEMINI_API_KEY | ключ из https://aistudio.google.com/apikey |
| GEMINI_MODEL | gemini-2.5-flash |
| JWT_SECRET | длинная случайная строка |

PORT задавать НЕ нужно — Railway подставит сам.
Старые ANTHROPIC_API_KEY / CLAUDE_MODEL можно удалить — они больше не используются.

## Обновление уже развёрнутого проекта

1. Скачайте новый архив, распакуйте.
2. В репозитории GitHub (папка AiNote-backend-git) залейте изменённые файлы поверх
   старых: package.json, nixpacks.toml, server.js, src/gemini.js (новый),
   src/extract.js, routes/bookmarks.js. Файл src/claude.js удалите из репозитория.
3. Railway сам увидит новый коммит и передеплоит.
4. В Variables добавьте GEMINI_API_KEY и GEMINI_MODEL, нажмите Deploy.

## Проверка

`https://ВАШ-АДРЕС.up.railway.app/health` → {"status":"OK"}

## Особенности Gemini

- YouTube: ссылка уходит в модель напрямую, без скачивания — работает стабильнее всего.
- TikTok/Instagram: скачивается через yt-dlp, затем файл шлётся в Gemini.
- Бесплатный тариф Gemini: ~1500 запросов/день, Flash-модели, без карты.
- На бесплатном тарифе Google может использовать запросы для обучения — для видео-закладок некритично.
